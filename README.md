# Digio Capture Kit SDK

[![GitHub release](https://img.shields.io/github/v/release/digio-tech/sdk_ml_camera?label=release)](https://github.com/digio-tech/sdk_ml_camera/releases/latest)
[![License](https://img.shields.io/badge/license-Apache%202.0-blue.svg)](LICENSE)

Android SDK providing camera + on-device ML utilities used in Digio's
KYC flows (selfie capture, face crop, document capture).

Distributed as an AAR via JitPack.

## Version
Current: **5.1.36** — see [Releases](../../releases) for the changelog.

## Requirements
- Android `minSdk` 24
- AndroidX

## Installation

Add JitPack to your root `settings.gradle` (or project `build.gradle`):

```gradle
dependencyResolutionManagement {
    repositories {
        maven { url 'https://jitpack.io' }
    }
}
```

## Usage
Refer to Digio's integration guide for API entry points.
